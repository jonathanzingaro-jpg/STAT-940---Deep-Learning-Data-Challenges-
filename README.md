# STAT 940 – Deep Learning: Data Challenges

My solutions to the Kaggle data challenges in **STAT 940 – Deep Learning** (University of Waterloo, Fall 2023), rebuilt as clean, reproducible notebooks.

| Challenge | Task | Approach | Result |
|---|---|---|---|
| [Data Challenge 1](Data%20Challenge%201/) | Image classification (10 classes, 32×32 images) | Ensemble of ImageNet-pretrained ResNet-50 and VGG-16 (PyTorch, `timm`) | 95.1% validation accuracy |
| [Data Challenge 2](Data%20Challenge%202/) | Automated essay scoring (regression) | Ensemble of fine-tuned BERT, DistilBERT, ALBERT and GPT-2 (Hugging Face Transformers) | 0.335 RMSE on the Kaggle test set |

Each folder has its own README, notebook and `requirements.txt`.
